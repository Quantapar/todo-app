# Todo App

A simple, vanilla JavaScript todo application built to learn DOM manipulation and local storage.

## Features

- Add, edit, and delete tasks
- Mark tasks as complete
- Persistent storage using localStorage
- Clean, responsive UI

## Technologies Used

- **HTML** - Structure
- **CSS** - Styling
- **JavaScript** - DOM manipulation and logic
- **localStorage** - Data persistence

## What I Learned

- DOM manipulation (creating, updating, and removing elements)
- Event handling and user interactions
- localStorage API for persisting data across sessions
- Working with arrays and objects in JavaScript
---

Built as a learning project to understand fundamental web development concepts.
